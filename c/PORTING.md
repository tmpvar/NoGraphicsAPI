# C99 port conventions

`c/gpu.h` is a single-header C99 port of the Vulkan backend in `src/NoGraphicsAPI.cpp`. It is generated by `cmake -P c/amalgamate.cmake` from the
modules in `c/src/`. Never edit `c/gpu.h` directly.

## Base commit

The port translates the C++ sources at commit `04004140f5b3b8ec7c566fd43bfed77d586155f8` (2026-10-06, "Report graphics initialization and resource
creation failures"). To pick up later C++ changes, diff `src/NoGraphicsAPI.cpp`, `include/NoGraphicsAPI/NoGraphicsAPI.hpp`, and the bump allocator and
delete queue utility sources against that commit and apply the same changes to the matching module in the table below. Update this commit hash and the
one in the `gpu_api.h` header comment after each sync.

## Layout

| File | Content |
| --- | --- |
| `src/gpu_api.h` | Public declarations. Fixed; report needed changes instead of editing. |
| `src/gpu_internal.h` | Internal structs, pools, and shared static helper declarations. Fixed; report needed changes instead of editing. |
| `src/gpu_common.c` | Error reporting, pools, enum conversions, barrier helpers, copy regions. |
| `src/gpu_device.c` | Device memory layout, device creation and destruction, memory types, backing buffers, GPU heaps, timelines, caps. |
| `src/gpu_swapchain.c` | Surface swapchain, present contexts, acquire, present, format changes. |
| `src/gpu_resources.c` | Texture heaps, textures, aliases, render views, descriptor heaps and writes. |
| `src/gpu_pso.c` | Graphics, mesh, and compute pipelines. |
| `src/gpu_commands.c` | Command pools and buffers, submission, timestamps, and every recording command. |
| `src/gpu_utility.c` | Bump allocator and delete queue. |

The amalgamation order is the table order. `gpu_api.h` is emitted first, then everything else inside `#if defined(GPU_IMPLEMENTATION)`.
Module files start with `#include "gpu_api.h"` and `#include "gpu_internal.h"`; the amalgamation strips those lines.

## Rules

- C99 only. No C++, no VLAs, no `_Generic`, no C11 atomics or `_Thread_local`; use the wrappers in `gpu_internal.h`.
- `GPUDevice` is caller-owned opaque storage of `GPU_DEVICE_SIZE` bytes; the implementation's `GPUDeviceState` must fit it (static assert) and public
  entry points cast the handle once. `GPUDeviceInit` is a no-op returning false on storage whose `initialized` flag is set, so hot-reloaded code can
  call it every time; `GPUDeviceDestroy` zeroes the storage. A fresh init makes exactly one `GPU_ALLOC(desc->allocUser, size, 16)` call and carves every pool and array
  from that block with `GPU_ComputeDeviceLayout`; `GPUDeviceDestroy` releases it with `GPU_FREE`. Both macros are overridable before the
  implementation is included and default to aligned calloc/free. No other allocation anywhere. Objects come from the `GPUPool` members.
- Every C++ growth path becomes a fixed capacity from `GPUDeviceLimits`, enforced with `GPUAssert`. Creation beyond a pool's capacity returns `NULL`
  or an empty aggregate after reporting through the error callback, like any other resource creation failure.
- Public functions: `GPU` + noun + verb, named after the first parameter's type or the created type (`GPUTextureCreate`, `GPUDeviceWaitIdle`,
  `GPUTimelineSemaphoreWait`). Command buffer recording uses the `GPUCmd` prefix (`GPUCmdDraw`, `GPUCmdBegin`). Internal functions: `static`, `GPU_` + PascalCase. Types: `GPU` + PascalCase. Fields and locals: lowerCamel.
  Enum values and flag bits: `GPUType_UpperCamel`, for example `GPUFormat_Rgba8Unorm`. Scalars: `uint8_t..uint64_t`, `int8_t..int64_t`, `float`, `double`. Vectors: `GPUExtent3`, `F32x4`, and so on.
- Public functions take descriptor structs as `const T*`. `GPUGpuRange`, `GPUGpuCpuRange`, spans, and `GPUExtent3` pass by value.
- Every descriptor is valid zero-initialized. The implementation resolves zero fields at the point of use (`GPU_ResolveDeviceDesc`, `GPU_ResolveTextureDesc`, the sampler, PSO, viewport and depth-stencil paths); `GPUFormat_Undefined`, `GPUTextureType_Undefined`, `GPUFilter_Undefined` and `GPUCompareOp_Undefined` are enumerator zero for that reason. `timestampQueryCount` zero means no timestamp queries. There are no `GPU*Default()` functions; initialize with C99 designated initializers. Translate C++ `{}` to `{0}` or `memset`.
- Preserve the C++ behavior exactly: the same asserts, the same error-callback messages, the same Vulkan calls in the same order.
  Translate comments; do not add comments that restate the code.
- Keep the AGENTS.md rules that apply to C: minimal code, no trivial wrappers, 120-column lines, no shadow validation, early error checks only.
- Module-local helpers that are not declared in `gpu_internal.h` must be `static` and carry a module prefix (`GPU_Device`, `GPU_Swap`, `GPU_Res`,
  `GPU_Pso`, `GPU_Cmd`, `GPU_Common`) so concurrently written modules cannot collide inside the single translation unit.

## Verifying a module

```
cmake -P c/amalgamate.cmake
"C:/Program Files/LLVM/bin/clang.exe" -fsyntax-only -x c -std=c99 -Wall -Wextra -Wno-unused-function -DGPU_IMPLEMENTATION -I "C:/VulkanSDK/1.4.357.0/Include" c/gpu.h
```

Until every module exists, undefined static functions produce warnings; errors inside your module must be zero.

## Building

The Visual Studio ClangCL MSBuild toolset is not required. The script below runs clang-cl through NMake from a vcvars64 environment:

```
c\build.cmd Debug
ctest --test-dir c\build-Debug --output-on-failure
```

Clang is found at `C:\Program Files\LLVM\bin` or in the Visual Studio LLVM directory. The Visual Studio generator with the default MSVC toolset also
works: `cmake -S c -B c\build -G "Visual Studio 17 2022" -A x64`.

## Debug checks

`GPU_DEBUG` controls `GPUAssert`, the Vulkan validation layer and debug messenger, and every debug-only check. `gpu.h` defines it when `NDEBUG` is
absent, and the CMake `gpu` target defines it for Debug configurations. Define `GPU_DEBUG` yourself for a release build with checks, or define
`GPUAssert(condition, message)` before including `gpu.h` to route failures elsewhere. Do not test `NDEBUG` in library code.

## Optional C library hooks

The library uses the C library only for `memcpy`/`memset`/`memmove`, `abort`, and text formatting. Define `GPUAssert(condition, message)` or
`GPU_SNPRINTF(buffer, size, format, ...)` before the `GPU_IMPLEMENTATION` include to replace the defaults; the defaults include `stdio.h`.
Both hooks and `GPU_DEBUG` are implementation-only; the public declarations never depend on them.
